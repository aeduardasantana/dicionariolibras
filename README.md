# Dicionário Libras

Produto digital do ecossistema GEB, com origem tecnológica Compass Rose Systems.

## Objetivo

Organizar um acervo consultável de sinais em Libras com contexto, variação e referências. O projeto não deve ser apresentado como tradutor automático.

## Estrutura atual

- `index.html` — interface pública
- `style.css` — estilos responsivos
- `script.js` — busca, exploração e dactilologia
- `dictionary.js` — dados do acervo atual e normalização de busca
- arquivos `.png` — ilustrações legadas do acervo
- `Libras2020-Regular.ttf` — fonte usada na dactilologia
- `.github/workflows/deploy.yml` — deploy automático para Locaweb

## Publicação

Destino FTP: `public_html/dicionariolibras/`

Domínio: `https://dicionariolibras.compassrosesystems.com.br/`

## Próxima evolução editorial

Cada entrada deverá incorporar, progressivamente: acepção, mídia principal em vídeo, classe gramatical, região/variação, exemplo de uso, fonte, revisor, status de validação e versão.
